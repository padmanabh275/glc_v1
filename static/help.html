GLC v1 is the Session 11 gateway: V9 LLM routes plus channels, voice, and an out-of-band control plane. Default port 8111.

Quick start

cd glc_v1
uv sync --link-mode=copy   # OneDrive users
uv run glc serve
uv run glc token           # paste into dashboard → Save token

Channel layer (new in S11)

  • WS /v1/channels/<name> — adapter control plane (Bearer token or ?token=)
  • Envelopes: ChannelMessage in, ChannelReply out
  • 15 catalogue slots: telegram, discord, slack, signal, …
  • Trust levels: owner_paired, user_paired, untrusted

Control plane

  • POST /v1/control/pair — issue 6-digit pairing code
  • POST /v1/control/pair/confirm — confirm pairing
  • GET /v1/control/presence — live channels + paired users
  • POST /v1/control/kill — loopback kill switch

Voice

  • POST /v1/transcribe?prefer=… — STT (groq_whisper, whisper_cpp, gemini_live)
  • POST /v1/speak?prefer=… — TTS (kokoro, elevenlabs, cartesia, gemini_live, fallback)

V9-compatible LLM routes

Point existing S9/S10 clients at http://localhost:8111:

export LLM_GATEWAY_V9_URL=http://localhost:8111

Routes: /v1/chat, /v1/vision, /v1/embed, /v1/status, /v1/providers, …

Dashboard tips

  • Channels tab — view catalogue, test WebSocket echo, default channel signal
  • Control tab — pair owner before testing allowlists
  • Group vs DM (Signal) — set thread_id to group id for group replies
